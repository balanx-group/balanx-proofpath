Help with ProofPath Lab

ProofPath Lab is an open-source teaching tool maintained through the public project issue tracker. You can read existing issues without a private account; opening an issue requires GitHub sign-in. Support has no promised response time or service level.

Before opening an issue

  • Check the plugin version and the bundled case ID, such as PP02.
  • For “unknown case ID,” run the helper’s list command.
  • For a fixture integrity failure, obtain a clean package rather than bypassing the check.
  • If Python execution is unavailable, ask for a plain-language case explanation and do not treat it as an executed score.

Report the case ID, public plugin version and a minimal fictional decision that reproduces the issue. Public issues are visible to everyone. Do not include credentials, personal information, customer records or private source code.
