ProofPath Lab privacy

This notice describes the skills-only ProofPath Lab package by BalanX LLC.

What the package does

The package contains instructions, fictional fixture data, an icon and an optional Python checker. It has no BalanX-operated backend, account system, analytics, cookies, API connection or telemetry. The checker reads its bundled fixture file and the decision JSON explicitly supplied on standard input. It prints a result and makes no network calls or output files.

Your host and this website

Your AI host processes conversations, files and tool execution under its own settings and policies. Installing this package does not replace those policies or make a conversation private from the host. The documentation website is hosted by GitHub Pages, whose hosting and request handling are governed by GitHub’s policies. This package notice does not promise that the host or GitHub collects no information.

Support information

If you open a GitHub issue, the information you post is public and available to project maintainers and other readers. Keep reports synthetic and free of sensitive data. Use GitHub’s available account and issue controls for editing or deleting your own content. The package does not provide a separate server-side data store or deletion endpoint.

Use only synthetic decisions

The workflow is intended for the bundled fictional cases. Do not supply personal, health, financial, customer or confidential company records. The plugin does not need them.
