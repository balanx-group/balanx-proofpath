# ProofPath Lab 0.1.0

A skills-only plugin by BalanX LLC for exploring 16 public fictional workflow cases.
Bundled instructions work with a host that can read skill resources; optional
deterministic scoring requires Python 3. No MCP server or credentials are required.

The plugin can inspect a case, explain relevant record versions, and compare an
explicit decision with the bundled reference. It performs no live submissions.
The public expected labels and scripted comparison do not measure any model.

Package structure follows Agent Plugins 1.0. Install through a compatible host's
normal plugin workflow. This archive itself has not been installed, reviewed or
approved by OpenAI. Directory publication requires the remaining listing and
publisher checks described in the separate readiness report.
