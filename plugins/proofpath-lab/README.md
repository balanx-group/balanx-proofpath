# BalanX ProofPath Lab 0.1.1

A skills-only plugin by BalanX LLC for exploring 16 public fictional workflow cases.
Bundled instructions work with a host that can read skill resources. Executing
the optional checker requires the local interpreter documented in the command
examples. No server or credentials are required.

The plugin can inspect a case, explain relevant record versions, and compare an
explicit decision with the bundled reference. It performs no live submissions.
The public expected labels and scripted comparison do not measure any model.

Install through a compatible host's normal plugin workflow. This archive itself
has not been installed, reviewed or approved by a directory operator. Directory
publication requires the remaining publisher and portal checks described in the
separate readiness report.

This revision changes BalanX branding and descriptive copy only. The checker,
fixtures, supported commands and runtime requirements are unchanged.
